# Tarkov Key Guide

비공식 Escape from Tarkov 열쇠/키카드 가이드 초기 버전.

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root) → Save.

## 기능
- tarkov.dev GraphQL API에서 열쇠 데이터 조회 (인터넷 연결 필요)
- 이름 검색 및 임시 맵 분류 (정확한 맵별 분류는 후속 검증 필요)
- 브라우저별 보유 체크(localStorage)
- JSON 백업/복원
- 모바일 반응형 UI

## 한계
- 현재는 영문 이름 중심이며 한글 이름, 퀘스트 용도, 사용 위치의 검증 데이터가 아직 없습니다.
- 맵 분류는 이름 기반 추정이므로 부정확할 수 있습니다.
- API 응답/분류에 따라 열쇠 일부가 누락되거나 잘못 분류될 수 있습니다.
