# Tarkov Key Guide v0.4.1 — 맵 선택 표시 수정

기존 v0.4 기반 긴급 수정입니다. 사이트 디자인/데이터/API는 기존 기능을 유지합니다.

- **맵 선택 버튼이 API 데이터 로딩 여부와 관계없이 즉시 표시**됩니다. 맵 데이터가 0건이어도 화면에서 사라지지 않습니다.
- 상단 `v0.4.1` 표시 및 맵 선택 패널 추가 (올바른 버전이 배포됐는지 눈으로 확인 가능).
- `style.css?v=041` / `script.js?v=041`로 브라우저에 남은 구버전 캐시 재사용 방지.
- 맵 API 실패 시 실제 오류 이유 표시, 선택 맵 데이터가 비었을 때 안내 표시.
- `tarkov-key-guide-owned-v1` 보유 기록 및 기존 백업 형식, 데이터 캐시 키 유지.

## 설치

ZIP 압축을 해제한 **4개 파일(index.html, style.css, script.js, README.md)만** GitHub 저장소 `main` 브랜치 **최상위 폴더**에 업로드해서 기존 파일을 덮어쓰세요. 배포 완료 후 사이트 상단 `v0.4.1` 표시 확인.

## 주의

- 이 수정은 맵 **선택 버튼**을 고친 것이며 사이트 내부에 실제 맵 **이미지**를 추가한 것이 아닙니다. 상세 화면의 `지도 보기` 링크는 외부 사이트로 이동합니다.
- 맵 API가 실패하면 버튼은 정상 표시되지만 해당 맵에 매칭되는 아이템은 없을 수 있습니다.
- 이 환경에서는 실제 사용자 브라우저/배포 서버의 네트워크 API 응답을 직접 확인할 수 없으므로, 상태 메시지를 확인해야 원인을 확정할 수 있습니다.
