# Tarkov Key Guide v0.3

GitHub Pages에서 실행되는 타르코프 열쇠·키카드 도감. 서버/로그인 없이 동작합니다.

## v0.3 변경 사항

- 공개된 tarkov.dev 지도 잠긴 문 좌표를 열쇠 상세 정보에 표시합니다. **좌표는 게임 월드 좌표와 다를 수 있습니다.**
- API에서 제공하는 열쇠 사용 횟수를 표시합니다. 0은 무제한/미설정 가능성이 있으므로 별도 확인하세요.
- 퀘스트 한국어 이름 데이터가 제공되면 상세 정보에 함께 표시합니다.
- 열쇠 카드에 API에서 잠긴 문 좌표가 확인된 수를 표시합니다.
- 데이터 상태에 전체 개수/맵 연결 개수/좌표 연결 개수를 표시합니다.
- 기존 `tarkov-key-guide-owned-v1` 저장 키를 유지하므로 **기존 보유 기록을 그대로 사용합니다.**

## 적용 방법 (중요: 폴더 중첩 금지)

ZIP 압축을 풀고 안에 있는 `index.html`, `script.js`, `style.css`, `README.md` 파일만 GitHub 저장소 **최상위(root)**에 업로드해 기존 파일을 교체하세요. `tarkov-key-guide-v3` 폴더 자체는 업로드하면 안 됩니다.

Pages: Settings → Pages → Deploy from a branch → main → / (root).

## 주의 사항

- 모든 열쇠가 정확한 맵/좌표를 가진다는 뜻은 아닙니다. API에 연결되지 않은 정보는 '맵 미확인'으로 표시합니다.
- 방 번호, 정확한 문 입구, 파밍 수익, 드롭 위치는 아직 추가되지 않았습니다. 위키 링크로 확인하세요.
- 데이터 소스: https://tarkov.dev/ 와 https://api.tarkov.dev/graphql
- 외부 API 통신은 실행 환경에서 제한되어 실제 데이터 총 개수는 게시 사이트에서 확인해야 합니다.
- 보유 기록은 동일 브라우저에 저장됩니다. 개인정보 서버 업로드 없음.

비공식 팬 프로젝트입니다. Escape from Tarkov의 권리는 Battlestate Games 및 원 권리자에게 있습니다.
