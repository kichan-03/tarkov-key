# Tarkov Key Guide v0.5 — 지도 미리보기 / 좌표 탐색

v0.4.1을 기반으로 제작한 **기존 사이트 교체용 버전**입니다. 계정/서버 없이 GitHub Pages에서 동작합니다.

## 새로운 기능

- 맵 선택과 연동되는 **지도 미리보기**: 공개된 tarkov.dev SVG 이미지가 있는 맵은 사이트 안에 표시합니다.
- 지도 이미지 확대 슬라이더 / 원본 tarkov.dev 지도 링크.
- **잠긴 문 X/Z 좌표 분포도**: API에서 좌표를 실제로 제공하는 문만 점으로 표시합니다. 점 또는 아래 열쇠 목록을 누르면 상세 창이 열립니다.
- 상세 창의 `맵 위치 탐색에서 보기` 버튼을 누르면 해당 맵 좌표 분포도로 이동합니다.
- 맵 이미지 제공이 없는 경우 또는 이미지 로딩 오류 시 **명확한 안내와 외부 지도 링크**를 표시합니다.
- HTML에 `v0.5`를 표시하고 CSS/JS 캐시 URL을 `?v=050`으로 구분했습니다.

## 중요한 정확도 고지

- **좌표 분포도는 실제 지도 이미지와 겹쳐진 위치 마커가 아닙니다.** 게임 좌표를 X/Z 평면에 표시한 별도 좌표 시각화입니다. 이것을 실제 건물·층·방 위치와 혼동하지 않도록 UI에 반복 고지했습니다.
- SVG 자료가 제공되지 않는 연구소/미궁/아이스브레이커 등은 외부 지도 링크로 안내합니다.
- 퀘스트, 좌표, 키 사용 위치는 tarkov.dev GraphQL 데이터 제공 범위에 제한되며, 이 사이트는 수동으로 정보 정확성을 보증하지 않습니다.
- SVG 이미지는 원격의 tarkov.dev assets 서버에서 직접 로딩합니다. 네트워크 연결 및 원격 서버 상태에 영향을 받습니다. 해당 자료의 라이선스/출처를 존중하세요.

## 호환성 / 배포

- 보유 체크 저장 키 **`tarkov-key-guide-owned-v1` 유지**, 기존 JSON 백업(v1)과 호환.
- 기존 목록 캐시 v4 유지. API가 실패하더라도 맵 선택/미리보기 컨트롤은 계속 표시됩니다.
- ZIP 압축을 푼 뒤 **파일 4개만** `kichan-03/tarkov-key` 저장소 루트에 업로드하세요. 새 폴더를 올리지 마세요.
- Settings → Pages → main / (root) 그대로 사용. 최신 버전 배포 후 `Ctrl+F5`.
