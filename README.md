# Tarkov Key Guide v0.6 — 실제 지도 위 잠긴 문 마커

v0.5의 **4개 루트 파일**을 교체해 사용하는 GitHub Pages 정적 사이트입니다. 로그인이나 서버는 없습니다.

## 추가 기능
- 지원 맵의 **SVG 지도 위에** API 잠긴 문 X/Z 좌표에 해당하는 점을 표시합니다. 좌표와 지도 영역은 동일한 tarkov.dev 오픈소스 맵 설정을 기준으로 계산했습니다.
- 현재 표시 가능한 지도: 세관, 우드, 해안선, 리저브, 인터체인지, 스트리트, 등대, 그라운드 제로, 터미널.
- **팩토리**는 회전 90도 지도라 검증 전까지 실제 지도 위 마커를 비활성화합니다. 연구소 및 기타 SVG 미제공 지도도 기존 별도 좌표 분포도를 이용합니다.
- 지도 마커 전체/보유/미보유 필터, 마커 표시 끄기, 마커 클릭 상세 정보, 지도/마커 동시 확대.
- 같은 X/Z 좌표의 마커는 겹침을 줄이기 위해 하나로 묶고 건수를 표시합니다. 여러 열쇠는 우측 목록에서 각각 선택할 수 있습니다.
- 기존 v0.5 좌표 분포도, 맵 탐색, 열쇠 검색, 퀘스트 안내, 열쇠 직접 공유, JSON 백업 기능 유지.
- 기존 `tarkov-key-guide-owned-v1` 기록 및 백업 형식 v1 그대로 사용. `tarkov-key-guide-items-v4` 캐시 구조 유지.

## 중요: 정확도 안내
- 실제 좌표는 tarkov.dev에서 제공한 잠긴 문 위치에 한정합니다. 지도 경계 및 `coordinateRotation=180` 설정을 기반으로 매핑했습니다. 정확성은 원본 지도와 좌표의 최신 상태에 좌우됩니다.
- SVG 지도는 보통 특정 층의 그림입니다. **Y 높이는 2D 투영에 반영되지 않으므로 다른 층의 문이 같은 위치에 겹칠 수 있습니다.**
- 지도 위 좌표가 없어도 열쇠 자체는 목록에 남습니다. 지도 미지원/이미지 오류 시 우측 좌표 분포도와 tarkov.dev 지도 링크를 사용하세요.
- 모든 열쇠와 키카드를 망라했는지는 게임 패치/공개 API 분류에 따라 재검증해야 합니다.

## 업로드
1. ZIP 압축을 푼 후 파일 `index.html`, `script.js`, `style.css`, `README.md` 4개를 GitHub 저장소 **최상위**에 업로드해 교체합니다. 폴더나 ZIP 자체를 올리지 마세요.
2. Settings → Pages의 main/(root) 설정은 변경하지 않습니다.
3. Actions → pages build and deployment가 Success가 된 후 `Ctrl + F5`로 새로고침하고 상단 `v0.6` 확인.
