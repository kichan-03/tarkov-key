# Tarkov Key Guide v0.7.3 — 중복 맵 통합

기준: 사용자가 적용한 v0.7.2의 퀘스트 패널 및 지도 마커 기능.

## 변경 사항
- **야간 팩토리 (Night Factory / night-factory)** → **팩토리**로 통합
- **그라운드 제로 21+ (Ground Zero 21+ / ground-zero-21)** → **그라운드 제로**로 통합
- 맵 선택 버튼, 맵 필터, 지도 선택기에서 중복 맵을 따로 표시하지 않습니다.
- JSON API와 구형 GraphQL API의 맵 이름, 이미 저장된 브라우저 열쇠 목록의 맵 이름을 통일합니다.
- 통합된 맵의 잠긴 문 좌표, 입장용 열쇠, 키별 퀘스트 연결은 남기되 중복은 제거합니다.
- 퀘스트의 진행 맵·목표 맵 명칭도 동일한 맵 이름으로 표시합니다.

## 보존한 기능
- v0.7.2의 지도·마커·확대·퀘스트 패널 및 열쇠 검색/상세 정보
- 보유 체크 저장 키 `tarkov-key-guide-owned-v1`
- 데이터 캐시 키 `tarkov-key-guide-items-v4`
- JSON 백업 v1 및 기존 API 요청 코드

## 적용
GitHub Pull Request에서 Merge pull request → Confirm merge를 누릅니다.
GitHub Pages 배포가 성공한 후 Ctrl+F5로 새로고침하고 v0.7.3을 확인합니다.

## 참고
서로 같은 지형을 사용하는 맵 변형을 하나로 모은 것이므로, 야간이나 레벨 제한 등 게임 규칙 자체가 사라지는 것은 아닙니다. 이 사이트는 열쇠 도감이므로 동일한 위치 정보는 하나의 맵 아래에서 조회합니다.
