# Tarkov Key Guide v0.7.2 — 맵별 연관 퀘스트 패널

v0.7.1의 **잠긴 문 좌표 분포도** 영역을 **선택한 맵의 열쇠 관련 퀘스트 목록**으로 변경했습니다.

## 주요 변경
- 왼쪽 **실제 지도 및 잠긴 문 마커** 유지.
- 오른쪽에 현재 맵의 열쇠와 연결된 퀘스트를 중복 없이 표시.
- 퀘스트 아래에 해당 열쇠 이름과 보유 여부를 표시하고, 열쇠 버튼을 클릭하면 상세 창을 엽니다.
- 퀘스트 제목을 펼치면 기존 **퀘스트 목표 확인** 기능이 동작합니다.
- API에 연결 정보가 없는 경우 빈 목록과 안내 문구를 표시합니다.
- 관련 퀘스트의 모든 목표가 반드시 이 맵에서 진행된다는 의미는 아닙니다.

## 호환성
- 기준: 실제 GitHub 저장소 main 브랜치의 v0.7.1.
- 지도 위 마커, 지도 확대, 검색, 필터, 열쇠 상세, 백업 기능 유지.
- `tarkov-key-guide-owned-v1` 저장 키와 `tarkov-key-guide-items-v4` 캐시 키 변경 없음.
- 백업 JSON 버전 1과 외부 API 쿼리 변경 없음.

## 적용
Pull Request에서 **Merge pull request**를 누르면 저장소 main 브랜치에 반영됩니다. GitHub Pages 배포가 성공하면 새로고침 후 **v0.7.2**를 확인하세요.

## 한계
맵/퀘스트/열쇠 간 연결은 공개 데이터에 의존합니다. 공개 데이터가 누락된 연결은 표시할 수 없습니다.
