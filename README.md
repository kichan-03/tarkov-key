# Tarkov Key Guide v0.7 — 열쇠 상세 정보 확장

기존 v0.6을 **수정 없이 기반으로 사용**한 GitHub Pages용 정적 웹사이트입니다. 로그인·별도 서버는 필요하지 않습니다.

## v0.7 추가 기능

- 각 카드의 **상세 보기**에서 사용 맵, 건물/층/방 번호 단서, 잠긴 문 좌표, 관련 퀘스트를 구역별로 확인합니다.
- 영문 아이템 이름에서 **명시적으로 읽을 수 있는 방 번호만** 건물·층·방 번호 카드로 정리합니다. 예: `Dorm room 206 key` → `기숙사 / 2층 / 206`, `Health Resort west wing room 301 key` → `리조트 서관 / 3층 / 301`. `Pinewood`, `Concordia`, `Chekannaya`의 명시적 호수도 이름 단서로 표시합니다.
- **이름 단서와 API 맵/문 좌표 확인 데이터를 다른 배지로 구분**합니다. 이름 단서는 별도 지리적 정확도 검증을 의미하지 않습니다.
- **'방 번호 단서 있음'** 필터와 건물명/방번호 검색 추가.
- 좌표마다 **지도에서 보기** 버튼을 제공해 v0.6의 LOCATION ATLAS로 이동할 수 있습니다.
- 관련 퀘스트를 펼치면 tarkov.dev GraphQL에서 개별 퀘스트의 **담당 상인·진행 맵·전체 목표·한국어 목표(있을 때)·위키 링크**를 추가로 가져옵니다. 목록 로딩을 막지 않으며 요청에 실패하면 재시도 버튼을 표시합니다.
- 각 퀘스트의 목표는 퀘스트 전체 목표이며, **모든 목표가 해당 열쇠를 필요로 한다는 뜻은 아닙니다**.

## 기존 기능과 호환성

- 기준 소스: 사용자가 실제로 배포한 `kichan-03/tarkov-key`의 v0.6 HTML, CSS, JS와 동일한 Git blob 해시 확인 후 작업했습니다.
- `tarkov-key-guide-owned-v1` 키와 백업 JSON `version: 1` 그대로 유지 → **브라우저별 기존 보유 현황 및 백업 호환**.
- `tarkov-key-guide-items-v4` 캐시 구조 유지. v0.6 지도/마커/확대/좌표 분포도/맵 필터/공유 링크 그대로 사용.
- 기존 GraphQL **핵심 아이템·맵 쿼리는 변경하지 않았습니다**. 신규 퀘스트 상세 쿼리는 사용자가 관련 퀘스트를 열 때만 별도로 실행하며 실패해도 핵심 데이터에 영향이 없습니다.

## 적용 방법

1. ZIP을 압축 풉니다.
2. 압축 안의 **`index.html`, `script.js`, `style.css`, `README.md` 네 파일만** GitHub 저장소 `kichan-03/tarkov-key`의 **최상위(root)**에 업로드하여 동일한 파일을 교체합니다. ZIP/폴더 전체를 업로드하면 안 됩니다.
3. `main` + `/(root)` GitHub Pages 설정은 유지합니다.
4. **Actions → pages build and deployment → Success**가 표시된 뒤 사이트에서 `Ctrl+F5` 새로고침하고 `v0.7`을 확인합니다.

## 알려진 제한

- 실제 API 서버와의 실시간 요청은 개발 컨테이너에서 접근할 수 없어 검증하지 못했습니다. 모의 응답 기반 브라우저 테스트만 통과했습니다.
- tarkov.dev의 잠긴 문에는 건물/층/방 이름 필드가 없어, 아이템 이름에서 읽은 정보 외의 방 번호는 **임의 생성하지 않습니다**.
- 한국어 퀘스트 목표가 미제공되면 영문 목표가 표시됩니다. 개별 퀘스트의 API 호출 실패 시 재시도 기능을 제공합니다.
- SVG 지도 없는 맵은 이전처럼 외부 지도/좌표 분포도를 이용합니다. 없는 맵 추가는 향후 계획입니다.
- GraphQL 서버가 불안정하거나 응답하지 않는 경우 실시간 아이템/퀘스트 로딩이 실패할 수 있으며, 브라우저에 이전 목록이 저장돼 있다면 이를 표시합니다.
