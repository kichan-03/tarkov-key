# Tarkov Key Guide v0.7.1 — 열쇠 검색/로딩 긴급 수정

v0.7 소스를 그대로 바탕으로 한 기존 사이트 교체용 버전입니다. `index.html`, `script.js`, `style.css`, `README.md` 4개만 최상위 루트에 덮어쓰면 됩니다.

## 수정
- 구형 GraphQL API가 장시간 장애가 발생해 빈 화면이 되는 문제에 대응하기 위해 **새 JSON API (`json.tarkov.dev/regular/*`)를 우선 사용**합니다.
- JSON API가 실패하면 기존 GraphQL로 한 번 더 시도하고, 그래도 실패하면 브라우저에 남아 있는 기존 캐시를 계속 사용합니다.
- 새 JSON 응답 형식의 열쇠 분류(category id), 영문/한글 번역 맵, 잠긴 문 연결, 퀘스트에서 필요한 열쇠 참조를 새 형식에 맞게 변환합니다.
- 검색 결과가 0개일 때 원인 안내 및 검색·필터 전체 초기화 버튼을 제공합니다.
- **보유 기록** `tarkov-key-guide-owned-v1` 및 JSON 백업 v1은 변경하지 않았습니다.
- 지도 SVG, 위치 마커, 상세 보기, 방 번호, 퀘스트 확대 표시 등 기존 기능을 유지합니다.

## 테스트
1. GitHub Pages Actions 배포 성공 후 상단 `v0.7.1` 확인.
2. 데이터 상태 영역에 `열쇠 ###개 로딩 성공 · json.tarkov.dev` 표시되는지 확인.
3. 모든 필터를 전체로 한 뒤 `206`을 검색하고 열쇠 카드를 확인.
4. 카드 맨 아래 `상세 보기` 클릭 후 방 번호와 관련 퀘스트 펼쳐보기.
5. 보유 체크 후 새로고침하여 체크 유지.

실시간 JSON 서비스에서 내려오는 데이터 구성이 변경되면 맵/퀘스트 연결의 일부가 표시되지 않을 수 있습니다. 브라우저 API 통신은 실제 배포 환경에서 추가 확인하세요.
