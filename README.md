# Tarkov Key Guide v0.4

Escape from Tarkov의 열쇠·키카드를 맵별로 찾아보고 브라우저별 보유 현황을 체크하는 **비공식 커뮤니티 도감**입니다. GitHub Pages에서 동작하며 로그인이나 서버가 필요하지 않습니다.

## v0.4 개선 사항

- **기존 v0.3 소스 그대로 기반**: 네 파일만 교체하며, 이전 보유 기록 `tarkov-key-guide-owned-v1`과 백업 형식(`version: 1`)을 유지합니다.
- **맵 바로가기**: 많이 사용되는 맵을 위쪽 버튼에서 빠르게 선택, 지도별 목록 개수 표시.
- **사용 위치 단서**: 기숙사·리조트 동관/서관 등 이름에 건물·방 번호가 명시된 일부 열쇠에 한해 층/방을 참고 표시. **이름을 바탕으로 한 추정이며 확인된 사용 위치가 아닙니다.**
- **정보 신뢰도 분리**: 공개 API에 연결된 맵은 `API 확인`, 이름 단서만 있는 맵은 `이름 단서`로 표기합니다. 맵 분류 시 추정 항목도 필터에 표시되지만 시각적으로 구분됩니다.
- **잠긴 문 좌표**: API에서 제공하는 좌표를 표기하고, 필요 전력 여부가 true이면 함께 표시. API는 모든 문의 방/건물명을 제공하지 않으므로 지도·위키를 함께 안내합니다.
- **지도 보기**: 맵 확인 또는 이름 단서가 있는 항목에서 tarkov.dev 지도 링크 제공. 좌표를 지도에 정확히 찍는 기능은 아직 없습니다.
- **개별 열쇠 링크 공유**: 상세 정보 → '이 열쇠 링크 복사'. `?key=<아이템 ID>` URL로 열쇠 상세를 직접 엽니다.
- **검색 확대**: 한국어/영어 아이템 이름, 방 번호, 관련 퀘스트 한국어/영어 이름, 이름 단서를 검색합니다. 띄어쓴 검색어는 모두 포함되는 방식입니다.
- **추가 필터**: 맵 입장용 열쇠, 좌표가 공개된 열쇠만 보기.
- **안정성 강화**: API 일부 오류 시에도 유효한 데이터가 있으면 이용하고, 한국어/맵 조회 실패 시 캐시의 기존 정보를 유지합니다. v0.3 캐시도 읽을 수 있습니다.

## 설치 (GitHub Pages)

1. ZIP 파일을 압축 풉니다.
2. 폴더 안의 **파일 4개만** `kichan-03/tarkov-key` 저장소의 최상위 경로(root)에 업로드하여 기존 파일을 교체합니다.
3. `Settings → Pages`에서 `main / (root)` 설정 유지. 배포 후 `Ctrl + F5`.
4. 폴더 자체(`tarkov-key-guide-v4`)를 업로드하지 마세요. 새로운 저장소를 만들 필요도 없습니다.

## 데이터와 한계

- 외부 API: [tarkov.dev](https://tarkov.dev/) / [GraphQL API](https://api.tarkov.dev/).
- 아이템 목록은 API의 `items(types:[keys])` 분류입니다. API가 모든 특수 키 아이템을 담는지 추가 검증 필요.
- API의 `Map.locks`에는 문의 위치 좌표가 있지만, 모든 문에 대한 방 번호나 건물 이름은 제공되지 않습니다.
- '이름 단서' 분류는 정확한 위치 검증이나 파밍 가치를 의미하지 않습니다. 출입구 정보는 위키나 실제 게임과 대조해야 합니다.
- 사용 횟수 0은 무제한을 확정하는 정보가 아닙니다. 장비 버전/패치마다 해석이 달라질 수 있습니다.
- 본 사이트는 계정/DB를 사용하지 않습니다. 같은 기기·브라우저에서만 체크가 저장되며 캐시/브라우저 기록 삭제 시 없어질 수 있습니다. JSON 백업을 이용하세요.
- Escape from Tarkov는 Battlestate Games의 상표입니다. 이 사이트는 공식 프로젝트가 아닙니다.

## 개발 테스트

JavaScript 문법 검사 및 모의 API 브라우저 시나리오 테스트는 구현 환경에서 수행합니다. **실제 tarkov.dev API 호출 성공 여부와 전체 항목 정확성은 사용자 브라우저에서 별도 확인**해야 합니다.
